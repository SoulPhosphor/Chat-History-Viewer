    Labels

    Configurable labels for staging groups of conversations. A conversation can carry several. Names carry no built-in meaning — you choose them, and a name is optional.

    Label settings

    Turn labels on to show them on conversations. Turning them off hides every label control but keeps your label data intact.

    Enter labels below or no labels will be applied.

    Label definitions

    Add, rename, recolour, reorder, or delete labels. The order here is the order clicking a conversation's square cycles through. Names are optional — a label with no name is a colour-only square.

    Labels will only show if square + label display is selected above.

    Drag a row by the grip on its right edge to reorder — or click the grip to pick the row up, then click where it should go. With the keyboard: focus a grip and use ↑ / ↓ (Home / End to jump to either end).

      Bulk Label Conversations

      Select conversations by criteria — different fields are combined with AND, multiple values in the same field (Current label, Folder, Tag, Keyword) are combined with OR — then choose whether the chosen labels should be Added, Removed, or Cleared on the batch. Added/Removed only touch the labels you pick, leaving any other labels those conversations carry alone; Cleared removes every label a conversation has. Nothing here deletes, archives, or moves conversations. Preview temporarily filters the conversation list to the batch so you can look through it. Preview is optional — Apply works on its own. Choosing "First" under Limit and applying fewer than everything that qualifies saves the rest as an Unfinished Label Run below, so you can pick up where it left off.

      Unfinished Label Runs

      Saved bulk-label runs that have started but aren't finished yet. Criteria are frozen from when the run began and can't be changed here — the only thing you can edit is how many to process in the next batch. Continue always picks up exactly where the run left off in its original ordered set, no matter what labels, tags, or folders those conversations have since had. A finished run moves to Recent Bulk Changes below.
